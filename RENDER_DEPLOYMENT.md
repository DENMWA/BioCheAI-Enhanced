# BioCheAI Enhanced - Render Deployment Guide

This guide explains how to deploy BioCheAI Enhanced to Render.com for production use.

## 🚀 Quick Deploy to Render

### Option 1: One-Click Deploy (Recommended)
1. Fork this repository to your GitHub account
2. Connect your GitHub account to Render
3. Create a new "Blueprint" service in Render
4. Point to your forked repository
5. Render will automatically detect the `render.yaml` and deploy all services

### Option 2: Manual Service Creation

#### Backend API Service
1. **Create Web Service**
   - Name: `biocheai-backend`
   - Environment: `Python 3`
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python run.py`
   - Plan: `Starter` (or higher for production)

2. **Environment Variables**
   ```
   FLASK_ENV=production
   DATABASE_URL=[Auto-generated by Render PostgreSQL]
   SECRET_KEY=[Generate secure random string]
   JWT_SECRET_KEY=[Generate secure random string]
   REDIS_URL=[Auto-generated by Render Redis]
   ```

#### Frontend Static Site
1. **Create Static Site**
   - Name: `biocheai-frontend`
   - Build Command: `cd biocheai-frontend && npm install && npm run build`
   - Publish Directory: `biocheai-frontend/dist`

2. **Environment Variables**
   ```
   VITE_API_BASE_URL=https://biocheai-backend.onrender.com/api
   VITE_WEBSOCKET_URL=wss://biocheai-backend.onrender.com
   ```

#### Database Services
1. **PostgreSQL Database**
   - Name: `biocheai-db`
   - Plan: `Starter`

2. **Redis Cache**
   - Name: `biocheai-redis`
   - Plan: `Starter`

## 🔧 Configuration

### Environment Variables
The following environment variables need to be configured in Render:

#### Backend Service
- `FLASK_ENV`: Set to `production`
- `DATABASE_URL`: Auto-generated by Render PostgreSQL
- `SECRET_KEY`: Generate a secure random string (32+ characters)
- `JWT_SECRET_KEY`: Generate a secure random string (32+ characters)
- `REDIS_URL`: Auto-generated by Render Redis

#### Frontend Service
- `VITE_API_BASE_URL`: URL of your backend service
- `VITE_WEBSOCKET_URL`: WebSocket URL of your backend service

### Custom Domains (Optional)
1. Add your custom domain in Render dashboard
2. Update CORS settings in `app.py` to include your domain
3. Update frontend environment variables with your custom domain

## 🆘 Troubleshooting

### Common Issues
1. **Build Failures**: Check build logs for dependency issues
2. **Database Connection**: Verify DATABASE_URL environment variable
3. **CORS Errors**: Update allowed origins in backend configuration
4. **WebSocket Issues**: Check WSS URL configuration
5. **Static Files**: Ensure build output directory is correct
